## 1. 공통 규칙 (모든 템플릿)

- 해상도 **720×1280** (9:16), 30fps, mp4 (H.264 + AAC) — 팀 결정(11/06): 원본 분석값 1080×1920 대신 720p. **합성은 브라우저**(#27·#28: 캔버스 + WebCodecs → 서버 업로드)
- **전환 효과 없음**: 모든 클립은 하드 컷으로 넘긴다. 페이드·슬라이드·줌 전환 금지.
- **텍스트 애니메이션 없음**: 등장/퇴장 효과 없이 바로 표시한다.
- 미디어는 `object-fit: cover`로 화면을 꽉 채운다. 늘리거나 레터박스 처리하지 않는다.
- 사진은 클립 길이 동안 1.00 → 1.05배로 아주 천천히 확대한다(사진이 멈춰 보이지 않게). 동영상 클립은 확대하지 않는다.
- 동영상 클립은 길이를 맞춰 자른다(가장 움직임이 많은 구간 우선, 어렵다면 앞부분).
- 세이프존: 화면 위 10%, 아래 15%에는 텍스트를 넣지 않는다(인스타 UI에 가려짐).
- 텍스트는 흰색, 약한 그림자(`0 1px 4px rgba(0,0,0,0.5)`), 크기는 작게(본문 기준 화면 너비의 약 4~5%).
- 모든 클립에 같은 색 보정을 적용한다(대비 +5%, 채도 +10% 정도). 클립마다 다른 필터 금지.
- BGM은 무료 음원만 사용한다. BPM 120 곡이면 1.0초 컷이 2박자, BPM 150 곡이면 0.8초 컷이 2박자에 맞는다.
- 총 길이는 10~30초.

## 2. 템플릿

좌표 `y`는 화면 높이 대비 비율(0 = 위, 1 = 아래)이다.

### `emotional` — 감성
- 용도: 감정·생각 위주의 일기
- 컷 길이: 2.5초
- 특수 구간: 영상 중간(약 15~20%)에 사진 6~10장을 0.15초 간격으로 빠르게 넘기는 "플래시 몽타주" 1회 — **사진이 6장 미만이면 생략**
- 텍스트: 컷마다 바뀌는 가사형 문장
  - 윗줄: 영어 번역(30자 이내), 작은 글씨, 노란색(`#F5D547`), 화면 너비의 약 3%
  - 아랫줄: 한글 1~2줄, 흰색
  - 위치 y = 0.62, 가운데 정렬
- 일기를 짧은 문장 여러 개로 나눠 클립 수만큼 배정한다.

### `montage` — 몽타주
- 용도: 사진이 많은 날, 여행·풍경
- 컷 길이: 1.0초 고정
- 텍스트: 영상 내내 고정
  - 제목: 장소명 영문 대문자, 굵은 산세리프, 화면 너비의 약 6%, y = 0.22
  - 부제: 한글 한 줄, 작게, 제목 바로 아래
  - 가운데 정렬

### `review` — 리뷰
- 용도: 맛집·장소 소개, 여러 곳을 다닌 날
- 컷 길이: 1.0초
- 텍스트:
  - 고정 제목: `지역 [동네]` 형식, 세리프체, y = 0.19
  - 고정 부제: 한 줄 요약, 반투명 검은 배경 박스, 제목 바로 아래
  - 하단 자막: 컷마다 바뀌는 구어체 한 줄(예: "가격도 착하고", "또 뭐 먹으러 가지?"), y = 0.72
  - 가운데 정렬

### `closeup` — 클로즈업
- 용도: 음식·물건 한 가지에 집중한 날
- 컷 길이: 0.8초
- 텍스트: 왼쪽 정렬 3줄(장소 / 대상 / 한마디), 예: "성수동 / 간장게장 막국수 / 떴다 …"
  - 위치 x = 0.08, y = 0.65
  - 주제가 바뀔 때만 교체한다(보통 영상당 1~3회).

## 3. AI 편집 플랜 생성

일기 텍스트와 미디어 목록을 LLM에 넘겨 아래 JSON을 받는다. 렌더러(브라우저 `app/src/lib/reelFrame.ts`·`encodeReel.ts`)는 이 JSON만 보고 영상을 만든다. 실제 API 응답에서는 `clips[].src` 대신 `mediaUrl`, `flashMontage.srcs` 대신 `mediaUrls`(`/media/..` 상대경로) — `docs/planning.md` 계약 참고.

### 템플릿 선택 기준 (프롬프트에 포함)
- 감정·생각 표현이 중심 → `emotional`
- 장소 하나 + 풍경 사진 다수 → `montage`
- 여러 장소/가게, 먹거나 한 것 나열 → `review`
- 음식·물건 하나에 집중 → `closeup`

### 출력 JSON 스키마

```json
{
  "template": "emotional | montage | review | closeup",
  "clipDuration": 1.0,
  "bgmBpm": 120,
  "fixedText": {
    "title": "INCHEON [송도]",
    "subtitle": "중간고사 끝난 날"
  },
  "clips": [
    {
      "src": "img1.jpg",
      "type": "image | video",
      "caption": "드디어 시험 끝",
      "captionEn": "Finally, exams are over"
    }
  ],
  "flashMontage": {
    "startIndex": 3,
    "srcs": ["img4.jpg", "img5.jpg", "img6.jpg"]
  }
}
```

- `fixedText`: `montage`, `review`, `closeup`에서 사용. `closeup`은 `title`에 3줄을 `\n`으로 구분해 넣는다.
- `clips[].caption`: `emotional`, `review`에서 사용. 15자 이내 구어체.
- `clips[].captionEn`: `emotional`에서만 사용.
- `flashMontage`: `emotional`에서만 사용, 나머지는 생략.
- `clipDuration`은 템플릿 기본값을 쓰되, 총 길이가 30초를 넘으면 클립 수를 줄인다.

### 프롬프트 예시

```
너는 인스타그램 릴스 편집자다. 아래 일기와 미디어 목록을 보고
4개 템플릿(emotional, montage, review, closeup) 중 하나를 골라
지정된 JSON 스키마로만 출력해라. 설명은 쓰지 마라.
캡션은 15자 이내의 자연스러운 구어체로, 일기 내용을 그대로 복사하지 말고 요약해라.

[일기]
{diary}

[미디어]
{media_list}
```
